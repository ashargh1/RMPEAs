Note: This document describes the complete pipeline for generating data, training the model, and reproducing the figures in the manuscript. The framework includes the following 
eight components:

component 1. Sample Generation
SampleGeneration.ipynb generates the training samples in two part:
Part A) It generates Samples.txt, containing 50,000 RMPEA samples at T = 850 K.
Part B) It expands each composition to 6 temperature points, resulting in Samples_T.txt with 300,000 total samples and generates Samples_T.txt.
Note: Each line in both files correspond to the compoistion of one smaple where the format of each line is [Ti,Fe,Al,V,Ni,Nb,Zr,Temp,Press]


component 2. Phase Labeling
PhaseLabeling.ipynb assigns phase labels using Thermo-Calc. The input file is Samples_T.txt while it generates Phases.txt, where the format of each line is 
[id,Ti,Fe,Al,V,Ni,Nb,Zr,Temp,Press,FCC,BCC,HCP,B2,Laves,Sigma,Heusler,Liquid]


component 3. Feature Labeling
FeatureLabeling.ipynb generates the 51 input features for each sample in two part.
Part A) It uses Samples_T.txt and Phi.txt as the main input files and generates labels.txt (primary features) as the output.
Part B) It uses labels.txt as the main input file and generates labels_extra.txt, which includes all 51 features (primary + secondary).
Note_1: Phi.txt must be generated by running the publicly available ASAP code using systems.txt, where each line defines a composition in the format of Ti0.35Fe0.10V0.35Zr0.20
Note_2: The format of both Label text files is [id,Ti,Fe,Al,V,Ni,Nb,Zr,Temp,Press,Feat1,....Feat51]

component 4. Feature Engineering
FeatureEngineering.ipynb performs a two-stage feature engineering process. In the first stage (i.e., data cleaning):
Part A) It performs initial screening.
Part B) It removes samples that make the distribution less uniform. You need to run this part multiple times until you stop seeing the message: "Number of deleted RMPEAs = ...".
Part C) It compiles the cleaned dataset.
In the second stage (i.e., feature reduction):
Part A) It identifies highly correlated features to be removed.
Part B) It drops the selected features and generates the final training/test sets: xlo_1.npy, ylo.npy, xlo_test1.npy, ylo_test.npy
Note: For consistency in later steps, we rename: xlo_1.npy to xlo.npy and xlo_test1.npy to xlo_test.npy


component 5. Model training
Initially, you need to do hyperparameter tuning through Bayesian optimization. For that, you need to first execute MLP_Finetuning.ipynb to select the best model architecture. The 
output of this code is BO_Restuls.txt wherein each line correponds to the architecture of the model and the format of each line is [dropout,dropout_rate,batch_normalization,batch_size,layers1,layers2,neurons,learning_rate,validation loss,testing loss]
You need to choose the architecture based on the value of the final collumn. Next, you need to train the final MLP model using the optimized architecture from the earlier stage via 
MLP.ipynb on xlo.npy, ylo.npy, xlo_test.npy, and ylo_test.npy.


component 6. Performance evaluation
PerformanceEvaluation.ipynb generates Figure 2-4 and Table 1 in the manuscript.


component 7: Spider plot
SpiderPlot.ipynb generates Figure 5 in the manuscript.


component 8: Empirical equation and SVM
SVM.ipynb trains a support vector machine to classify single-phase BCC. In the next stage, EmpiricalEquation.ipynb uses the trained SVM to create Figure 6.
